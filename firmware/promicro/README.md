# Legacy Arduino Pro Micro Prototype

This directory is retained for historical reference only. The target architecture has changed to a dedicated ESP32-S3 kiln controller. Do not extend this Pro Micro firmware for the four-zone production design unless the architecture decision is explicitly revisited.

The current target design is documented in:
- [System architecture](../../docs/ARCHITECTURE.md)
- [Hardware selection](../../docs/HARDWARE.md)
- [Architecture decisions](../../docs/DECISIONS.md)

No Pro Micro pin mapping or output wiring should be used for the target system.
